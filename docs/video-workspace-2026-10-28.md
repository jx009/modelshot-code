# 视频制作与视频生成（2026-10-28）

## 实际观察与实现边界

通过用户浏览器观察 Cheso 首页、公开视频案例、已有视频生成项目，并发送一次获授权的六秒纯文字制作请求。账户显示积分从 1142 降至 1004；发现其反复检查帧后已停止任务，没有继续付费试验。

- 视频生成：已有项目输出 MP4，有播放、下载、文件历史与对话记录。
- 视频制作：案例与试验产出 `.vmotion` 工程、`DESIGN.md`、字体与媒体资源；先确认方案，再制作，并通过对话修改。
- 页面公开的源码查看器显示 `.vmotion` 是 HTML、时间清单和按时间定位的渲染函数。该次作品的在线预览加载失败，因此没有验证其全部播放器交互。
- 本项目独立实现上述两个入口和核心工作流。动效以受约束场景 JSON 保存，浏览器本地预览，私有 FFmpeg 服务导出 MP4；**不是 Cheso 私有工程运行时的完整复制，也不支持导入其 `.vmotion`**。不复制其品牌或私有代码。

## 功能与入口

首页 AI 创作下选择「视频制作」或「视频生成」。工作台路径 `/video?mode=motion`、`/video?mode=video`，保存后使用 `/video?document=<id>`。项目列表含两种类型。

- 制作：描述要求、拖入图片/视频/音频，模型返回完整分镜方案；确认后本地播放，可继续对话修改。
- 编辑：场景拖动排序、添加/复制/删除、撤销重做、文字与字号、颜色、对齐、入场动画、素材入点、原声和背景音频音量。
- 预览：24fps 时间轴、播放/暂停、拖动定位、双击全屏；逐帧更新时间只影响播放器，编辑不会触发服务器渲染。
- 导出：单独提交 MP4 任务，完成后任务卡直接查看/下载；可保存与导入**本账号**的工程 JSON（素材引用不随 JSON 打包）。
- 生成：复用 Ark 视频通道，支持纯文字或一张首帧图片，5/10 秒及四种比例。模型是否支持这些选项取决于配置的上游模型。
- 状态：后台排队/运行/失败/完成、取消请求、自动显示结果；保存采用版本检查、幂等键和本地未保存草稿恢复。

当前制作边界：1–40 场景，单场景1–30秒，总时长≤180秒；每个场景一层背景媒体、标题和副标题；淡入/上移/缩放入场；输出短边720像素（16:9为1280×720），24fps。不包含自动检索版权素材、生成配乐/配音、任意图层时间线、复杂 HTML 动画或 Cheso 所有特效。浏览器与服务器字体渲染可能存在差异。上传视频最好使用 H.264/AAC MP4；MOV 编码的浏览器兼容性依设备而定。

## 首页共用输入框

- 视频制作、视频生成与海报、演示文稿等入口共用 `CreationComposer`，统一输入区、附件位置、参数菜单、积分和发送按钮；各业务仍保留自己的提交接口和费用校验。
- 视频比例、时长、平台画幅预设与工作台入口收在参数菜单，平台预设只调整比例，不替换提示词。图片素材显示缩略图，支持在输入框内粘贴图片。
- 首页保留每种视频模式尚未提交的提示词；输入框随首页加载，不再单独异步下载视频入口，也不引入工作台整份样式。能力接口区分加载、失败和不可用状态。
- 本次只统一入口，不调整视频项目自动保存、任务轮询及工作台运行机制，也不新增部署参数。
- 补充 `tests/unit/video-launcher.test.jsx` 覆盖共用布局、输入保留、预设不覆盖、能力状态、粘贴、输入法和视频提交契约；按服务器限制只做静态校验，测试留待 CI 执行。

## 权限、费用与部署

### 工作台布局整合

- 视频工作台复用演示文稿的 `WorkspaceSplit`、宽度偏好和公共顶栏。`WorkspaceHeader` 通过插槽将项目名、保存状态和视频操作呈现在外层顶栏，不再另建视频项目顶栏。
- 删除视频内部项目栏、对话标题栏、输出文件名工具条与移动端第二排切换栏。保留一条主顶栏；文件/对话切换、编辑、撤销、导出在此统一操作，手动保存、工程导入/下载和主题切换收进更多菜单。
- 文件列表默认折叠，时间轴和场景属性仅在编辑模式展开。播放比例与生成状态并入播放控制；添加场景进入时间轴，不再单独使用标题行。视频布局改用公共主题变量，缩减卡片边框和留白，预览跟随可用高度。
- 删除根布局旧 `Navbar` 与独立 `PricingPage` UI、注册和样式。充值、购买记录、使用记录仍由现有弹窗提供；后台计费和支付通知逻辑不变。
- `/pricing` 仅保留服务端兼容跳转到首页 `?panel=recharge`，保留合法订单参数。新 Stripe / 易支付充值返回同样直接打开该弹窗；支付到账仍由服务端查询确认，URL 参数不作为支付成功凭据。
- 新增工作台单顶栏、模式操作、移动端切换、插槽卸载、旧定价地址和弹窗返回的回归用例；更新本地路由用例。只完成改动文件静态检查，未运行构建、测试或浏览器，视觉与真实支付返回仍需 CI / 部署环境验证。

### 部署与权限

管理员「创作开放开关」新增视频制作/视频生成。普通用户需 workspace 和对应模块开关，提交任务另需 runs 开关；ROOT 绕过访问开关，不能绕过缺失模型/worker/tools。旧七开关配置会把新增两项默认关闭，其他配置保持不变。

- 视频生成：在管理员「模型配置 → 视频模型」中选择视频接口协议，配置显示名称、模型 ID / Endpoint ID、API Key、自定义 Base URL 与每次生成积分，可设置默认模型。未配置数据库视频通道时继续兼容 `ARK_API_KEY`、`ARK_VIDEO_MODEL`、`ARK_BASE_URL`。
- 方案生成：现有管理员语言模型/规划模型；上传图片最多取前三张缩略图作为视觉参考，视频/音频仅向规划模型提供名字及长度，不声称理解所有镜头。
- MP4 合成：配置现有 `STUDIO_TOOLS_URL`、`STUDIO_TOOLS_KEY`，**更新 tools 镜像**（新增 FFmpeg、Noto CJK）以及 web、worker。只更新 web 镜像不能导出。
- 不需要新增数据库迁移，工程存储在 StudioDocument JSON，媒体由原资产系统管理。
- 积分：沿用任务预约/结算/失败退款机制。方案费用跟随规划模型，已配置的视频通道使用该模型的每次积分，旧环境变量模式使用视频工具积分，导出工具默认0积分；界面展示服务器报价，提交重新核对。
- 媒体单文件≤64MB，导出引用素材总量≤256MB，输出≤128MB；私有合成并发为1，繁忙时返回明确错误。用户资源须归本人所有；不接受任意远程媒体地址。

镜像发布完成后，在 `/www/modelshot` 使用现有流程拉取并更新 `tools web worker`。compose.prod.yaml 已使用 env_file，新增模型变量放入 `.env.production`；管理员持久化开关优先于环境默认值。

### 视频与创作配图模型选择

- 第三方不按域名或模型名限制，而是按实际视频协议接入：OpenAI Videos 兼容（multipart `POST /videos`、`GET /videos/{id}`、带认证的 `/content` 下载或结果 URL）；方舟 / Seedance 兼容（`/contents/generations/tasks`）；百炼 / 万相兼容（异步 `/services/aigc/video-generation/video-synthesis`、`/tasks/{id}`）。这些都可以填写自建或第三方 API 前缀，不能把只兼容聊天接口的服务当作视频服务。
- 每个视频通道可声明文生、图生或两者均支持，以及允许的时长。Videos 协议支持 4/8/12 秒及横竖 720P；其余协议可从 4/5/8/10/12/15 秒勾选供应商实际支持的时长。方舟保留四种比例，万相提供横竖与方形。切换模型会选择兼容参数，服务器在扣费前复核输入限制；不偷偷丢弃用户参考图片。
- 首帧在 Videos / 万相协议下转换为匹配画幅的无透明 PNG。万相图生使用 `img_url` 与 `resolution`，文生使用 `size`；供应商模型必须与所选输入能力对应。图片补边而非拉伸，源文件不修改。
- 模型选项一起保存到任务快照；请求不自动跨域跳转。Videos 成品下载限制 100 MiB，跳转到签名 URL 时不转发 API Key，并继续使用现有公网地址校验下载器。新增适配回归用例，未在本机运行真实第三方请求或测试套件。

- 视频生成首页入口、视频工作台共用模型选择组件，选择保存在工程中；任务提交携带模型通道与报价，后台保存实际模型、协议与接口地址，轮询沿用任务快照，不随默认模型变化切换上游。已停用、已删除或接口变化的所选通道不会静默切换到其他模型。
- 「视频制作」是大语言模型规划 + 素材合成，不是视频模型生成，仍沿用后台规划模型，不展示无效的视频模型下拉框。
- 海报：首页和工作台支持选择公开生图模型；AI 配图报价、总预算和后续生成使用同一通道。取消 AI 配图仍只生成文字与排版。
- 演示文稿：首页和工作台选择配图模型，先生成大纲；在大纲确认面板可再次选择配图模型，按实际配图数量重新核算积分与预算，确认后才生成配图。首轮不会把幻灯片错误地当作海报配图任务执行。
- 未确认请求仍保留原始通道和报价，重试不重新选择默认模型。模型列表仅返回显示名称、通道标识和价格，不返回密钥。
- 本次模型选择无需新增环境变量、数据库迁移或修改 compose；发布时将 `web`、`worker`、`creation-worker`、`creation-language` 更新到同一版本。已有 ARK 环境配置继续有效；本次没有新增 tools 依赖。
- 新增模型路由、报价、快照轮询、首页选择及大纲配图选择回归用例。本机仅做限定文件静态校验，未运行用例或真实生成；须在 CI / 验证环境确认。
