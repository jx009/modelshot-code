# 顶部公告

入口：`/zh/admin/announcements`（后台「公告管理」）。Admin 与 ROOT 均可配置，普通用户无权访问配置接口。

1. 新建公告，填写标题、纯文本内容；按钮链接可选，支持站内路径或 http(s) 地址。
2. 选择风格、优先级、允许关闭；英文内容可选，未填时回落中文。
3. 可设开始/结束时间，编辑器使用管理员本地时区，接口保存 UTC。开始时间包含边界，结束时间不包含边界。
4. 勾选启用后点击「保存所有公告」。多个公告同时生效时按优先级降序、ID 升序选择一条。关闭高优先级公告不会立即弹出下一条。

前台首页、灵感、项目、电商及画布等页面共享公告条。管理后台使用预览，不展示公共公告。公告在切页、窗口获得焦点及每 60 秒重新读取；关闭状态存在 sessionStorage，当前会话内不重复显示同一版公告，内容更新后重新展示。无公告或关闭时不留空白；ResizeObserver 同步侧栏、导航、画布及移动端工具开关位置。

实现参考 LetAiCodeWeb2 的公告服务与 AnnouncementBanner：复用启停、优先级、时间窗口、风格、按钮及关闭逻辑，适配本站 Next.js / Prisma / 主题变量。纯文本经 React 转义，不渲染后台输入的 HTML。未引入参考项目的 Ant Design、MySQL 原生 SQL 或居中弹窗。

配置存入现有 SystemConfig 的 `announcements`，最多 20 条，无需新增数据库迁移。`GET /api/announcements/current` 仅返回当前有效内容，不暴露草稿；后台 GET/PATCH `/api/admin/announcements` 做鉴权、输入验证、事务审计、幂等与版本冲突保护。审计保留修改前后完整公告。发布不经过缓存，其他管理员修改会返回 409，页面提示重新加载。

验证：公告规则/接口单元测试，数据库持久化、审计、并发冲突集成测试，以及桌面/手机首页、项目页、画布、关闭与更新重新出现的浏览器测试。上线需要更新应用并重新构建。
