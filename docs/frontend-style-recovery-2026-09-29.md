# 首页样式故障修复与验收

用户截图显示导航成为浏览器默认带下划线链接、按钮回退为原生灰色、主题颜色与案例画板背景丢失。2026-09-29 对线上 `/zh` 的检查：四个 CSS 请求均为 200，主样式包含主题变量和 Tailwind reset；新浏览器上下文中页面正常。因此不能把历史截图的具体触发原因断言为服务器缺文件或浏览器缓存。

故障注入已复现：阻断根 CSS 下载会丢失主题和链接 reset。Chromium 在下载失败时仍可能留下非空 `link.sheet`，读取 `cssRules` 才会抛错，单纯检查 `sheet` 不足以发现失败。

本次变更：

- 在根布局安装 CSS 恢复逻辑，仅针对同源 Next 静态样式。按原级联顺序重试两次，避免自动刷新造成未保存内容丢失；持续失败显示独立于外部 CSS 的刷新提示。
- Docker 发布以 workflow 的 BUILD_TAG 作为 Next deploymentId，构建和运行阶段一致，减少旧标签页导航时的新旧资源混用。版本参数放在依赖安装之后，保留 npm ci 镜像层缓存。
- 放大侧栏标签和辅助文案、改善输入提示的对比度，移动端保留历史入口并隐藏重复品牌字样，避免挤压语言和账户操作。

验收：生产构建、静态检查通过；`tests/e2e/styles.spec.mjs` 在桌面和手机共 8 项验证明暗主题、登录后的首页/灵感/项目/素材/画布、直接加载和客户端导航、单次 CSS 故障恢复与持续故障提示。页面截图保存在对应 Playwright 测试产物中。

范围限制：这次是样式可靠性和可读性修复，不代表参考站的全功能或全视觉对齐已经完成。部署后仍需在用户原来出现问题的浏览器环境确认。

## 同轮追加的交互修复

- 输入框移除突兀的白色内部焦点框，改为整个输入面板的柔和 focus-within 提示，键盘焦点仍可辨认。
- 局部修改去掉矩形识别和物体识别切换，局部修改/消除共用绿色自由画笔，默认 8 屏幕像素；松手闭合选区，提交蒙版包含轮廓内部。光标直径与当前画笔一致，不再受图片主色影响。
- 画布保存最近使用项目；从导航返回自由画布恢复它，只有明确的新建入口另开空白画布。同画布多次对话保持同一 documentId，首次提示词命名，后续对话保留名字。
- 首页、案例卡片、项目列表和历史入口关闭无关 RSC 预加载；导航显示反馈并阻止等待期间重复点击产生重复请求。等待超过 8 秒后再次点击可以直接打开目标页面。

导航诊断：本次直连线上 `/zh/projects` HTML 约 1368ms、RSC 约 1289ms，`/api/auth/session` 约 326ms，均成功返回。未获取用户出错当时的网络 Timing 或服务器 CPU/数据库监控，因此不能断言截图中的挂起由 CPU 不足引起。前端请求堆积与无反馈已覆盖，真实网络和服务器延迟仍需部署后确认。
