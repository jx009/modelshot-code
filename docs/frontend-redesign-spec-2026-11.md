# 前端重做方案 · 视觉、动效与工程规范

> 目标：把一个"功能齐全但看起来像 demo"的站点，做成可以和主流 AI 生图 / 生视频产品同台比较的产品界面。
> 本文只描述"做成什么样、怎么验收"，不包含代码。

---

## 0. 结论先行

对标 Fotor、即梦、Krea、Midjourney 网页版之后，差距集中在三件事上，而不是单个页面好不好看：

1. **没有视觉纪律**：四种按钮、八种圆角、十种字号、满屏渐变和光晕。用户看到的是"拼出来的"，不是"设计出来的"。
2. **没有内容前置**：首屏是一个输入框加一排标签，看不到任何作品。用户第一眼无法判断"这里能做出什么"。
3. **没有反馈质感**：生成中的等待、图片加载、切换页面，都是"卡一下然后出现"。主流产品的每一次状态变化都有过渡。

因此方案按三条主线推进：**建立纪律（设计系统）→ 内容前置（页面结构）→ 反馈质感（动效系统）**。

## 1. 设计方向

### 1.1 一句话定位

> 作品是主角，界面是画框。

所有视觉决策都服从这一条：任何装饰都不能比作品更抢眼。

### 1.2 三条铁律

| 铁律 | 含义 | 反面案例（现状） |
| --- | --- | --- |
| **单强调色** | 全站只有一个高饱和色：品牌橙 `#FF6A2B`。渐变只允许出现在"生成中"和"可点击的主操作"两处 | 极光四色背景 + 彩虹渐变标题 + 黄绿按钮 |
| **最小界面** | 无内容区域的边框、阴影、背景一律去掉；用留白和层级区分 | 每个面板都有描边 + 卡片阴影 + 内高光 |
| **动作即反馈** | 任何超过 100ms 的状态变化都要有过渡；任何超过 300ms 的操作都要有进行中提示 | 提交后界面僵住，直到结果出现 |

### 1.3 与 Fotor 的关键对照

| 维度 | Fotor | 我们（改版方案） |
| --- | --- | --- |
| 首屏背景 | 单色暗蓝 + 一道光 | 真实作品墙（四列纵向滚动）+ 指针聚光灯 + 中心遮罩 |
| 标题 | 产品名 + 一行能力清单 | 两行超大标题（88–104px），第二行用强调色 |
| 输入框 | 一个，4 个控件 | 一个，按类型切换，控件收在框内，默认显示 5 个 |
| 入口 | 带缩略图的胶囊 | 带缩略图的胶囊（4 个，第一屏可见） |
| 内容区 | 统一尺寸的场景卡 + 标签 | 12 个场景卡横向滑动 + 灵感瀑布流 |
| 信息密度 | 低，大量留白 | 首屏密集（作品墙），内容区中等 |

**核心差异策略**：Fotor 的首屏是"能力介绍"，我们改成"作品即介绍"。用户不需要读文案就能理解产品能做什么。

## 2. 设计系统

### 2.1 色彩

只有一层语义色板，所有组件只允许引用语义变量。

#### 深色（默认）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg-page` | `#09090A` | 页面底 |
| `--bg-card` | `#121214` | 卡片、输入框底 |
| `--bg-elevated` | `#17171A` | 浮层 |
| `--bg-card-hover` | `#1C1C1F` | 悬停 |
| `--divider` | `#232327` | 分割线（只用 1px） |
| `--primary-text` | `#F4F2EE` | 主文字（象牙白，禁纯白） |
| `--secondary-text` | `#A6A4AB` | 次文字 |
| `--tertiary-text` | `#8A8890` | 辅助文字（禁止再小） |
| `--primary` | `#FF6A2B` | 唯一强调色 |
| `--primary-muted` | `rgba(255,106,43,.14)` | 强调色的低饱和铺底 |
| `--danger` | `#FF6B5E` | 错误 |
| `--success` | `#4FD1A1` | 成功 |

#### 浅色

主背景 `#F7F6F3`（暖纸白），强调色压暗到 `#C9430C` 以保证白字对比度 ≥ 4.5:1。

#### 使用规则（写进 lint）

- 组件内禁止出现十六进制色值。
- 强调色在一屏内最多出现 2 处（主按钮 + 一处高亮）。
- 渐变只允许 `--gradient-primary`（主按钮）与生成中的骨架流光；禁止用渐变做标题文字（除非是营销页，且每页最多一次）。
- 阴影只有三档：`--depth-1`（卡片）、`--depth-3`（浮层）、`--depth-5`（模态）。

### 2.2 字体与字号

| 用途 | 字体 | 字号 | 字重 | 行高 | 字距 |
| --- | --- | --- | --- | --- | --- |
| 首屏大标题 | Geist + 思源黑体 | `clamp(46px, 7.6vw, 104px)` | 750 | 1.02 | -0.045em |
| 区块标题 | 同上 | `clamp(26px, 2.6vw, 38px)` | 700 | 1.2 | -0.03em |
| 卡片标题 | 同上 | 16px | 600 | 1.4 | -0.01em |
| 正文 | 同上 | 14px | 400 | 1.65 | 0 |
| 辅助/标签 | 同上 | 13px | 500 | 1.4 | 0 |
| 最小文字 | 同上 | 12px | 500 | 1.4 | 0.04em |

**规则**：
- 全站禁止小于 12px 的文字。当前有大量 9–11px，这次全部清掉。
- 数字（积分、价格、尺寸）统一 `font-variant-numeric: tabular-nums`。
- 中文标题加 `text-wrap: balance`，避免最后一行只有一两个字。
- 英文眉题使用全大写 + 0.12–0.16em 字距，作为"设计感"的锚点，每屏最多一次。

**字体落地**：中文字体需要本地托管子集（MiSans 或 HarmonyOS Sans，按常用 3500 字子集化，约 300–500KB），否则 Windows 上会回落到微软雅黑，标题的方正感会丢失。

### 2.3 间距、圆角、尺寸

- **间距**：4 的倍数，只用 4/8/12/16/20/24/32/40/48/64/80。
- **圆角**：`--radius-sm 8`（控件）、`--radius-md 12`（输入框内元素）、`--radius-lg 18`（卡片）、`--radius-xl 28`（首屏输入框）。禁止任意值 `rounded-[13px]`。
- **容器**：`prose 680 / content 1080 / wide 1440 / full 1680`。全站只用这四档。
- **点击区域**：最小 36×36，移动端 44×44。

### 2.4 动效系统

#### 时长与曲线

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-fast` | 140ms | 悬停、颜色变化 |
| `--dur-base` | 240ms | 展开、折叠、透明度 |
| `--dur-slow` | 480ms | 入场、页面切换 |
| `--ease-out-expo` | `cubic-bezier(.16,1,.3,1)` | 默认曲线（入场、位移） |
| `--ease-spring` | `cubic-bezier(.34,1.36,.64,1)` | 弹性反馈（缩放、弹出） |

#### 六种标准动效

| 名称 | 效果 | 应用位置 |
| --- | --- | --- |
| **升入** `lh-rise` | 上移 26px + 模糊 10px → 清晰 | 首屏标题、输入框、卡片逐个入场（每级延迟 60–70ms） |
| **渐显** `reveal` | 模糊 14px → 清晰，透明度 0 → 1 | 所有图片加载完成时 |
| **弹性缩放** `pop` | scale .8 → 1.06 → 1，透明度同变 | 上传缩略图、结果图出现 |
| **悬停抬升** | translateY(-4px) + 阴影加深 | 卡片、场景卡 |
| **聚光灯** | 跟随指针的径向光斑，写入 CSS 变量，不触发 React 渲染 | 首屏作品墙 |
| **骨架流光** | 渐变背景横向移动 | 图片未加载时的占位 |

#### 原则

- 进场动效只播一次，不重复。
- 交互动效必须可中断：鼠标移开立刻回落，不排队。
- 所有动效在 `prefers-reduced-motion: reduce` 下关闭，不能只关一半。
- 性能红线：任何动效只允许改 `transform` / `opacity` / `filter`，禁止改 `width`、`top`、`margin`。

### 2.5 组件清单（第一期 16 个）

| 组件 | 变体 | 现状问题 |
| --- | --- | --- |
| Button | primary / secondary / ghost / danger，3 尺寸 | 现有 6 种写法 |
| IconButton | 3 尺寸 + tooltip | 无统一焦点态 |
| Segmented | 文字 / 图标 / 带缩略图 | 标签样式不一致 |
| Select | 单选、多选、可搜索 | 使用原生 `<select>` |
| Input / Textarea | 默认、聚焦、错误、禁用 | 边框颜色不统一 |
| Combobox（模型选择） | 分组 + 搜索 + 价格 | 已有，需视觉统一 |
| Popover | 定位 4 向 | 手写多处 |
| Dialog | 确认 / 表单 / 全屏编辑器 | 尺寸混乱 |
| Toast | 成功 / 失败 / 进行中 | 位置和样式不统一 |
| Tooltip | 4 向 | 缺失较多 |
| Tabs | 下划线 / 胶囊 / 图标 | 三种混用 |
| Card | 默认 / 交互 / 作品 | 阴影不统一 |
| Skeleton | 文本 / 图片 / 卡片 | 只有一种 |
| Progress | 线性 / 环形 / 分段（多张图） | 缺失 |
| EmptyState | 图标 + 标题 + 操作 | 纯文字 |
| Avatar | 圆形，渐变环 | 已有 |

统一放在 `src/components/ui/primitives/`，每个组件一个文件 + 一个 `*.module.css`，不使用全局类名。

## 3. 页面方案

### 3.1 全局外壳

**桌面端**
- 顶部横向导航（高 64px，滚动后毛玻璃），左侧 logo，中部导航，右侧积分胶囊 + 头像。
- 导航项：首页、图像、视频、PPT、电商、作品、素材。
- 不再使用左侧竖向导航轨（当前版本已改为横栏）。
- 内容区最大宽度 1680px，两侧留白 40px。

**移动端**
- 顶栏 56px：菜单按钮 + logo + 登录。
- 抽屉式导航。
- 底部不放 tab bar，避免与工作台工具栏冲突。

**紧凑工作区**（图像画布、视频、PPT）
- 外壳让位给页面自身的工具栏，顶栏压缩到 44–52px。
- 外壳只负责品牌、积分、账户三项，其余交给工作区。

### 3.2 首页

#### 结构（自上而下）

```
┌────────────────────────────────────────────────┐
│ 首屏（min 100svh）                              │
│  ├ 背景：四列作品墙，纵向无限滚动，-4° 倾斜      │
│  ├ 中心径向遮罩 + 四周渐隐                       │
│  ├ 指针聚光灯（screen 混合）                     │
│  ├ 眉题胶囊：图像 · 视频 · 演示文稿 · 电商套图    │
│  ├ 超大标题两行，第二行品牌橙                    │
│  ├ 副标题一行                                    │
│  ├ 输入框（统一，类型可切换）                     │
│  ├ 缩略图胶囊 ×4（做同款入口）                    │
│  └ 底部滚动提示                                  │
├────────────────────────────────────────────────┤
│ 场景区「快速上手」                              │
│  ├ 标题 + 「浏览全部作品」                       │
│  └ 12 张场景卡，横向滚动，4:5 比例                │
├────────────────────────────────────────────────┤
│ 灵感瀑布流                                      │
│  ├ 标题 + 说明                                   │
│  ├ 吸顶分类条 + 搜索                             │
│  └ 4 列瀑布流，悬停显示标题/提示词/做同款         │
├────────────────────────────────────────────────┤
│ 页脚                                            │
└────────────────────────────────────────────────┘
```

#### 首屏细节

- **作品墙**：32 张本地作品（`public/inspiration/generated/`），按宽高比均衡分四列，每列复制一份实现无缝循环，列速 78/104/88/118 秒，奇数列反向。整体 `rotate(-4deg) scale(1.12)`。
- **遮罩**：`radial-gradient(120% 78% at 50% 46%, rgba(6,6,7,.94) 0%, .9 34%, .5 62%, .94 100%)`，再叠加纵向渐变收边。
- **聚光灯**：`radial-gradient(360px circle at var(--mx) var(--my), rgba(255,255,255,.14), transparent 70%)`，`mix-blend-mode: screen`，指针进入淡入 500ms。
- **颗粒**：全局 SVG 噪点，opacity .06，消除大色块塑料感。
- **标题**：两行，第一行象牙白，第二行品牌橙并带 60px 外发光。

#### 输入框

- 外框：`rgba(18,18,20,.62)` + `blur(28px)`，1px 边框。
- 悬停：边框变品牌橙。
- 聚焦：边框橙 + 上浮 2px + 外圈 `0 0 0 5px` 的 14% 橙色光。
- 顶部类型行：图片 / 视频生成 / 视频制作 / PPT / 电商套图，选中项白字 + 12% 白底。
- 文本区高 116px，占位文字提到"玻璃温室"这类具体场景。
- 工具行：参考图（3 张限制）、模型、尺寸、张数、固定提示词，全部胶囊形，高 34px。
- 发送按钮：高 42px，橙底深字，左侧显示积分，右侧圆形箭头；悬停上浮并出现 6px 橙色光圈。
- 输入框下方 4 个缩略图胶囊：圆形缩略图 32px + 文字 + 箭头。

#### 场景区

- 12 个场景：电商主图、产品海报、食品广告、品牌视觉、人像写真、时尚大片、国风插画、3D 潮玩、漫画分镜、空间概念、AI 视频、一键 PPT。
- 每张卡：4:5 图 + 底部图标标签。
- 悬停：上浮 6px、图片放大 1.06、底部浮出「做同款」白色胶囊。
- 横向滚动 + 吸附，卡片宽 `clamp(180px, 19vw, 248px)`，逐个延迟 55ms 入场。

#### 灵感瀑布流

- 分类条吸顶，毛玻璃背景。
- 卡片圆角 18px，加载前显示流光骨架。
- 图片加载完成从模糊渐显。
- 悬停：上浮 4px、图片放大 1.045、底部渐变遮罩浮出标题 + 两行提示词 + 「做同款」。

### 3.3 图像工作台

当前最大的体验问题是**卡顿**和**生成过程没有反馈**，优先级高于美观。

#### 布局

```
┌──────────┬──────────────────────────────┐
│ 对话面板 │ 画布区域                      │
│ (320px)  │  ├ 顶部：项目名、保存状态、导出 │
│          │  ├ 画布（Konva）               │
│ 消息列表 │  └ 底部悬浮工具栏              │
│ 输入区   ├──────────────────────────────┤
│          │ 右侧：图层 / 任务（可折叠）     │
└──────────┴──────────────────────────────┘
```

#### 关键改造

1. **相机交互不进 React**：滚轮缩放与拖拽平移直接操作 Konva Stage，用 `requestAnimationFrame` 合并每帧一次，交互结束后 120ms 再提交状态。验收：缩放时单帧脚本耗时 < 8ms。
2. **拆分单体组件**：`StudioWorkbench`（95KB、约 40 个 useState）拆成顶栏、对话面板、画布区、工具栏、任务托盘，用切片 store 订阅。
3. **生成过程**：提交后立即插入占位卡（骨架 + 进度条），完成后图片从模糊渐显，结果卡悬停出现「重生成 / 变体 / 放大 / 局部重绘 / 转视频 / 下载」。
4. **空状态**：换成与产品相关的示例与三步引导，不再放无关风景照。

### 3.4 视频工作台

- 沿用同一套外壳与组件。
- 生成列表改为时间轴缩略图。
- 视频卡片自动静音预览，悬停播放。

### 3.5 PPT 创作

- 保留 HTML 幻灯片引擎（schemaVersion 3），删除旧版 Konva 布局编辑器。
- 左侧大纲，中间画布，右侧检查器。
- 缩略图栏可折叠。

### 3.6 电商套图

- 改造为「对话 + 计划卡」：左侧对话，右侧展示逐步生成的作品。
- 每张图带用途标签（主图 / 详情 / 场景）。

### 3.7 登录、账户、定价

- 使用同一套表单组件。
- 登录页改为左侧品牌 + 右侧表单的两栏布局，移动端单栏。

## 4. 性能

### 4.1 目标

| 指标 | 现状（估算） | 目标 |
| --- | --- | --- |
| 首屏 LCP | > 3s | < 2.0s（4G + 中端设备） |
| 交互 INP | 未知 | < 200ms |
| 画布缩放帧率 | 明显掉帧 | 稳定 60fps |
| `/studio-v2` 首屏 JS | 基线 | 下降 40% |

### 4.2 措施

> 完整审查见 `docs/perf-plan-review-2026-11.md`。下面第 0 项是该文档新增的交付层，收益最大，必须最先做。

0. **交付层**：公开页 HTML 发到香港、Nginx 开启压缩、`explore/[slug]` 静态化、排查长连接。当前中国网络首字节实测 7.9 秒，不修这一层，下面所有优化都会被网络等待吃掉。
1. 首屏作品墙图片分级：构建期生成 320 / 640 / 1280 三档，首屏只用 320–480，其余延迟加载；只加载视口内两列。
2. 公共数据服务端缓存：灵感库改为静态生成，接口不再 `no-store`；所有公共读接口加 TTL。
3. 启用 React Compiler 自动 memo，并用 Next 16 的 `cacheComponents` + `partialPrefetching` 逐步替换自研的页面保留外壳。
4. 翻译文件按命名空间下发，不再整包传入客户端。
5. `globals.css`（70KB）拆分：token 与基础样式保留全局，页面样式就近放置。
6. 任务状态统一 SSE 推送，删除各页面独立轮询。
7. 排查 CDN 静态资源偶发失败，修好后删除 `StylesheetRecovery` 兜底逻辑。
8. 画布改造见 3.3。

## 9. 风险

| 风险 | 应对 |
| --- | --- |
| 首屏作品墙拖慢 LCP | 只加载视口内图片，缩略图不超过 80KB |
| 动效过多导致低端机卡顿 | 统一走 transform/opacity，提供降级开关 |
| 视觉重做影响已有功能 | 按页面灰度，旧页面保留到新页面验收通过 |
| 中文字体子集遗漏生僻字 | 子集外字符回落到系统字体，行高保持一致 |
| 删除模块影响后台 | 后台对应入口同步移除，避免死链 |
