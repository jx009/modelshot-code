# 吱吱鼠视频接入

依据用户提供的 https://sub.zzshu.cc/video-guide 文档（2026-11-07）适配。

后台「模型配置 → 视频模型 → 新增模型」选择「吱吱鼠 · Seedance 视频生成」。默认模型 ID 为 `官转SD2.5-30图版-480P`、Base URL 为 `https://sub.zzshu.cc/v1`、时长为 5 秒。模型 ID 可替换为账号「可用渠道」中的完整名称；显示名称和用户积分由管理员设置。已配置的标准 OpenAI Videos 通道可直接在模型卡中切换协议，保留密钥、模型 ID 和地址。

- 提交使用 JSON `POST /v1/videos`：`model`、`prompt`、`duration`、`ratio`。分辨率以模型名固定的值为准，不额外强制 720p。
- 支持文生视频、多图、参考视频 / 音频及首尾帧。管理员按模型选择「参考图」或「首帧」：参考模式最多 30 张图片、10 段视频、10 段音频；首帧模式按图片顺序发送 `first_frame`、可选 `last_frame`，最多两张，不会混传参考素材。切换模型保留素材，超出当前模型能力时必须先移除素材。
- 参考音频每段至少 1.8 秒，总长不超过 30 秒。音视频上传复用 tools 服务的 `/motion/inspect`，检测结果由服务端加密绑定资产和账号，提交前校验所有权、类型、时长和项目素材一致性，再预留积分。需要配置现有 `STUDIO_TOOLS_URL`、`STUDIO_TOOLS_KEY`，上传不会调用付费视频模型。
- 提供参考素材时可不填提示词；没有素材时仍需填写。首尾帧模式和参考模式由管理员按模型设置，用户端显示对应限制。
- 素材不使用登录态地址、本地路径或 base64。worker 确认所有权后，创建一小时有效、绑定账号和资产的加密链接，供应商可直接读取 PNG 或音视频原文件（支持 Range）；访问时再次检查资产所有权及 active 状态。接口不缓存明文内容，不公开整个存储桶。
- 依赖现有 `NEXTAUTH_URL` 指向可被供应商访问的 HTTPS 站点，web 与 worker 使用相同的现有 `ENCRYPTION_KEY` 配置。无需新增数据库迁移或环境变量。
- 收到任务 ID 后保存并复用，每 30 秒 `GET /v1/videos/{id}`。`queued/processing` 等待、`completed` 完成、`failed` 失败，完成后通过带认证的 `/content` 下载 MP4；下载跳转不转发 API Key。
- 任务提交后发生结果不明的错误，不自动重新提交付费生成；有任务 ID 时继续查询。更新 web 和 worker 后生效。

为 JSON 参数、中文模型 ID、参考图/首帧互斥、异步查询与下载、通道校验、后台协议切换以及临时链接的资产绑定/过期/篡改校验补充回归用例。依照仓库资源限制，本机只做改动文件静态检查，不运行测试、构建、服务或真实付费生成。
