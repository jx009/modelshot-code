# 创作画布跟随逐页发布

## 原因

工作台以前在任务仍为 running/queued 时直接跳过作品更新；任务结束也只显示“打开最新作品”。编辑器只在挂载时读取作品，因此左侧已出现 V20，右侧仍可能停留在 V17。并行生成后，步骤的排列顺序也不代表作品版本的先后顺序。

## 修改

- 从成功步骤中按作品 ID 提取最高发布版本，生成期间就通知当前画布。重复或迟到事件不会降低目标版本；不同作品之间不比较版本号，也不抢占用户当前选择的其他文件。
- PPT 和海报共享的编辑器在原实例中读取并应用新版本，不再要求手动重新打开。页码选择、画布实例和同页 iframe 保留。
- 仅替换干净的编辑状态；GET 前后检查版本、内容引用、编辑器会话、未保存操作、文字草稿、拖拽和打开的编辑面板。读取过程中开始的编辑也受保护。发生版本冲突仍使用原有保留副本流程，不静默覆盖或自动重放修改。
- 编辑忙碌时延后同步；短暂读取失败会退避重试。已追上目标版本后停止重试，没有新增付费模型请求。

## 验证

补充工作台运行中更新/乱序版本/文件选择、journal 异步读写竞争、刷新延后/退避/取消的回归用例。依照 AGENTS.md 本次只执行改动文件 ESLint 和 git diff --check，未运行测试套件、构建或启动服务；实际浏览器行为仍需部署后验证。
