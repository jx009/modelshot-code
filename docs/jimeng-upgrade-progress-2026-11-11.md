# 图片与视频升级实施及验收记录

基线：`4b64f3b`。交付分支：`codex/jimeng-image-video-upgrade`。范围以 [升级规格](jimeng-image-video-upgrade-2026-11-11.md) 为准。代码实现、静态检查、CI、视觉和生成质量分别记录，不以实现存在替代验收。

## 规格与实现对应

| 规格 | 已实现的行为 | 验收边界 |
| --- | --- | --- |
| I-01 参考素材 | 主体／人物／风格／构图／场景语义角色；多图进入浏览器和后台计划；增删重排时同步图号，已删除指代阻止生成 | 角色通过文字策略表达；未宣称所有模型有原生角色或参考强度参数 |
| I-02 参数与报价 | 保留模型切换前输入；规划冻结通道及逐步报价；执行前校验价格，支持刷新；明确批量独立变体含义 | 未验证原生连贯组图的通道不显示该能力；基准图衍生依赖模型一致性 |
| I-03 连续编辑 | 来源资产／图层／任务、连线、原图对比、复用输入、从结果继续；复用同一资产进入电商基准图流程 | 复用提示词、模型和参考；不自动复现旧蒙版，需重新选区。电商逐张重做沿用现有流程 |
| I-04 编辑策略 | 官方 OpenAI 局部修改／扩图走原生 alpha mask，可选范围外保护及向内羽化；兼容网关保留引导图策略；任务冻结策略，历史任务维持旧路径 | 消除、文字编辑、OCR、拆层、超分保留真实服务路径；中文、标识、五官、边缘质量尚待实图验收 |
| V-01 共享面板 | 素材预览、类型／用途／数量校验、首尾帧交换、排序替换；共享模型和参数组件；具名模板和原作品选择器；管理员配置清晰度／声音／时长组合及价格 | 组合仅开放已配置能力；未配置的模型继续使用协议固定规格，不伪造分辨率或声音选项 |
| V-02 画布视频 | 工具条直接入口、多图用途确认、关联视频子文档、稳定任务位置、来源线、真实封面及尺寸／时长；打开工作台和加入分镜 | 移动源图不移动已预留结果位置；复制项目保留结果、清空进行中任务身份；复制前须恢复未确认提交 |
| V-03 视频 Tab／工作台 | 15 秒能力请求超时及重试；保留草稿和同一任务；任务进行时准备下一版；结果播放、下载、复用、参考、分镜交接 | 存储禁用时仅保证当前页面的内存恢复；已受理任务仍可经服务端项目查询找回 |
| V-04 成片编排 | 片段进入新建／已有动效工程；真实时长和裁剪；逐镜重做、原结果比较、只替换目标镜头；最多 12 镜的逐镜生成计划及总预算确认 | 新生成结果不自动覆盖工程；原素材变化时拒绝覆盖。编排是本站扩展，不宣称复制了即梦内部实现 |
| V-05 恢复与账务 | 图片／视频／分镜计划保留不确定请求的原 body 和幂等键；恢复不依赖先保存新草稿；后台串行生成、额度暂停、失败重试和取消沿用现有账务 | 不虚构排队位次／百分比；停止后续镜头不承诺取消已发生的上游费用；需 CI 故障与账务验证 |

后编辑只允许同一个上游服务账号、规范化地址和兼容接口的作品。凭据仅在服务端用于比对，不返回浏览器。每个视频分镜在同一事务中创建子文档、付费任务、步骤尝试和积分记录；已完成步骤在继续计划时保留。

## 对标证据

[Web 录屏对标记录](jimeng-web-reference-2026-11-11.md) 对应用户提供的三个教程位置。第 9 集为无限画布主依据，第 2 集补充连续编辑；新画布教程补充节点及成片编排，进入其他应用后的画面排除。已采集公开播放器画面；匿名 640×360 流只支持交互观察，不能据此签署像素级一致。未声称完整转录或听取音轨。

## 配置与部署

1. 保持现有 `CREATION_WORKSPACE_ENABLED`、`CREATION_RUNS_ENABLED`、视频／动效开关与账号权限。分镜生成需 `worker` 和 `creation-worker` 心跳正常；视频预览封面需同步部署 image-tools 服务。
2. 本次没有 Prisma 模型或迁移修改。新增字段位于已有文档／任务 JSON，沿用 `CreationRun`、`CreationStep`、`ProcessingStep` 和资产引用表。旧文档通过可选字段及默认值兼容。
3. GPT-Best 视频通道可配置 `videoVariants` 和 `videoFieldChoices`；这些是管理员已验证组合，不会自动发现供应商权限。每项报价为一次片段任务的总积分；不同时长价格不同应拆成不同选项。接口不能处理的参数不要写入配置。
4. 公共能力响应移除私有参数 payload，浏览器只选择组合 ID；入队时验证组合、冻结解析后的参数和价格，Worker 使用原快照。模板选择提交配置中的值，原视频操作通过作品选择器解析身份。
5. 图片原生 mask 仅对官方 OpenAI 地址启用；其他兼容端点使用参考引导策略。旧任务没有策略字段时保持旧行为。羽化只能改善选区过渡，不保证模型生成区域内的文字或商品细节。
6. 媒体检测复用受限 FFmpeg 服务和处理租约，封面作为共享资产登记引用；纯视频无字幕时预览／导出不额外压暗。画布仅显示可见任务卡与连线，视频由用户主动播放。

配置结构示例（示意值，不代表任何供应商已验证规格或价格）：

```json
{
  "videoVariants": [{
    "id": "verified-720-silent-5s",
    "label": "720p · 无声 · 5 秒",
    "resolution": "720p",
    "audio": false,
    "durations": [5],
    "ratios": ["16:9", "9:16"],
    "creditCost": 20,
    "parameters": {"resolution": "720p", "generate_audio": false}
  }],
  "videoFieldChoices": {
    "motion_id": [{"label": "已验证的镜头动作", "value": "verified-upstream-preset"}]
  }
}
```

`motion_id` 仅适用于声明该字段的接口，不能把整个示例复制给任意模型。分辨率和音频的上游字段名称也必须以该通道协议为准。暂不启用新通道时保留原配置即可；停用生成入口不删除既有作品或共享资产。
