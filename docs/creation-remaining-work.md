# 创作工作台剩余验收与能力边界

2026-10-25。旧清单中“没有 HTML 海报、没有跨类型 Agent、没有 Office 导入”的表述已过时。当前实现、入口、测试及部署见 [交付说明](archive/cheso-alignment-implementation-status.md)。完整范围仍以 [对标方案](archive/cheso-alignment-remaining-plan.md) 为准。

## 尚未实现的扩展或完整程度

| 项目 | 已交付 | 尚未达到原方案的部分 |
|---|---|---|
| PPT | HTML 页面、主题/共享母版、基本图表/表格、PPTX 导入导出 | 复杂 PPTX 组合/母版继承/特效保真；HTML 页面列表的全部缓存缩略图 |
| Office | 原 OOXML 保留、可编辑投影、基础范围回写、复杂内容保护 | 修订/域、富文本/保护/外链等复杂特性的任意范围编辑 |
| 表格 | 25 行区域分步生成、失败区域重试、串行组装、Univer | 10 万非空单元格目标、只加载当前可视区域的后端；完整作品仍限制 2 MiB |
| Agent | 注册工具、有界 DAG、跨类型子任务、确认/恢复/取消/导出 | 自动失败重规划、编辑已有计划；当前修改需求可发起新任务 |
| 网页 | 本地 ES 模块、静态发布、独立交互预览、源码/可视修改 | 动态 import、外部依赖/网络 API、任意框架运行；复杂页面不保证全部可视操作 |

这些边界没有伪装为已经实现的源码，也不应由用户以“大范围联调”的名义补写实现。
