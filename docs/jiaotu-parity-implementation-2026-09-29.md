## 行为与兼容约定

- 原图、抠图、物体移动与局改结果均归属项目，完成后追加画布。物体移动继续使用既有“源区域/目标区域引导完整场景编辑”云端链路。本轮没有重新引入本地分割模型，也没有宣称知道参考站的私有模型实现。
- 每个项目消息独立归档，当前快照保留最近 100 条，早期记录可分页查看。已应用结果另表去重；另存项目复制全部消息历史。新副本复制画布结果，不复制尚在执行的远程任务。
- 画布最多 1000 个对象，消息/已应用 ID 的输入上限为 20000，保存请求上限 4MB。超限明确报错；没有静默截断画布对象。几何仍整体写入 JSON，分批读取不等于无限对象场景已优化完成。
- 相机使用独立接口，平移不造成内容版本冲突；新项目第一次取得服务器 ID 时继承当前相机。
- 导出原图按资产去重加载，源像素合计设 80MP 上限，合成范围上限 40MP/单边 16000px，过大需缩小导出范围。PSD 为独立像素层；SVG 保留图片对象与原生文字，不把照片伪装成矢量路径。
- 素材回收只移除素材库条目；仍被项目、消息或任务引用的文件不会随条目到期删除。项目软删除保留引用，当前无自动到期清空项目策略。
- 使用记录显示当前可用积分及预留积分；现有账本未存逐笔余额快照，未编造历史余额。
- 管理员的语言模型用于提示词优化；用户仍只选择生图模型。模型成本由后台配置返回。

## 验证记录

全部测试只访问 loopback `modelshot_test`、Redis DB1 和测试对象存储；供应商调用使用本地测试服务，不消耗线上积分。

- 单元测试：23 文件，132 项通过。
- 集成测试：10 文件，69 项通过，包括批量操作跨用户拒绝、过期恢复拒绝、引用保留、创建幂等与长历史；最终文档保存查询调整后，相关 19 项再次通过。
- 浏览器全套：44 项，首轮 40 项通过，4 项因旧头像定位与弹窗焦点归还失败；修复后最后一次桌面/手机针对性复测 4/4 通过。过程中还修正了手机测试在结果自动切换画布后盲目切回聊天的时序假设。没有把首轮失败隐去或声称最终代码又全量重跑一次。
- 专项已通过：桌面/手机宫格交点、形状裁剪、六种导出、素材批量管理；提示词优化计费及相同请求重放；多图第二次请求响应丢失后重试仍只有两份任务与预留；电商全链路。
- `npm run check:static` 通过：ESLint、设计检查、719 项双语词条及 27 张本地演示素材。
- `npm run build` 生产构建通过。
- 24 个迁移在专用测试数据库的独立空 schema 完整部署通过，验证后仅删除该临时 schema。
- 独立 PSD 解析验证：合成 530×240；两层分别位于 `(0,0,240,240)` 和 `(290,0,530,240)`，透明角点正确。

截图与自动化报告为本机验证产物，位于 `test-results/`、`playwright-report/`；参考站证据位于 `.local/diagnostics/jiaotu-research-20260929/`。不将用户账户截图提交到公开仓库。

## 仍需完成的差异与上线验收

1. 猫、书、接触阴影案例的真实物体移动：必须得到完整场景，旧位置修复、目标位置唯一、没有黑块/贴图残影、来源图保留。Mock 只能证明协议与交互，不能证明这个效果。
2. 实际供应商的局改、扩图、分层、超清、文字替换与视频输出质量/耗时；线上模型路由与额度以管理员配置为准。
3. 整站逐状态视觉与动效对照、更多窄视口及触控细节；当前不宣称 60fps 或模型秒出。CSS 历史规则尚未全部归并。
4. 首页普通“开始创作”目前进入工作台并带入描述/模型；上传进入带参考图项目。首页的固定 prompt、数量/清晰度完整面板和一步发送仍有差异；工作台对应基础能力已经可用。
5. 素材分类的重命名/删除、画布批量选择/分组/右键细节、图内文字排版与参考站深层工具菜单仍待补齐或补查。SVG 自动换行与 Konva 文本的完全一致性未验收。
6. 多参考图直接生成已接入；多步骤规划当前仍限一张参考图。生成批次逐项提交，后台可并发执行，未做上游模型限额压力测试。
7. 参考站卡密、水印、发票及邀请深层行为未完成业务对齐；现有账户、购买与邀请逻辑保留。不能把这些算作已复制的功能。
