# 页面与画布加载排查（2026-10-18）

## 线上观测

以 `www.letaidraw.com` 的公开页面和未登录画布做读取测试，没有使用用户账号或生成图片。

- 静态资源返回 `X-HK-Static: local`，证实 Action 上传与香港本地读取生效。
- 一轮浏览器采样中，香港本地的约 9 KB JS 与约 1.6 KB CSS 均出现约 10 秒请求耗时，页面请求也出现约 10.7 秒；这些请求最终返回 200。
- 使用禁用系统代理的浏览器另测，访客画布首次可见约 1.7–3.7 秒，首页切回画布约 1.4–2.9 秒。此轮最终使用 HTTP/2，没有复现永久黑屏。不同时间、连接、代理环境不能直接作性能提升前后对比，也不能据此断定 HTTP/3 是原因。
- 截图展示的是 Fetch/XHR，无法从中判断具体私有图片的大小、传输与解码时间。私有画布图片不能在未登录测试中访问。

## 已发现并修复的代码问题

1. 全站每次路径改变调用 NextAuth `update()`，引入 CSRF 和 session 请求，并短暂把状态切为 loading。去除该刷新，保留定时、焦点、网络恢复和显式账户操作刷新；丢失登录态后的服务器验证恢复仍保留。
2. `useStudioProject` 依赖原始 sessionLoading，已知用户后台刷新时也会重新读取并重置画布。现在仅首次尚无用户身份时等待登录，工具能力与任务订阅同样不因 loading 波动重启。
3. 重开已有画布时，云端请求结束之前不显示本机副本。现在先绘制当前用户的本机草稿，版本核对完成前禁用编辑提交，保留原有未确认保存与版本冲突处理。
4. 云端读取缺少期限与明确的失败重试。现在单次打开最多等待 15 秒，退出/切换取消旧请求；没有可用副本时显示“重试打开”，不持续显示正在打开。
5. 图片只因占屏较大就自动下载原始文件，放大了跨洋流量。常规浏览使用 320/640/1280 WebP；只有选中图片、显示像素超过 1280 且稳定放大 700ms 才加载原图。原图下载、工具输入和导出不变。
6. 公告不再每次切页重新请求，仍定时刷新并响应焦点和管理更新事件。
7. 浏览器内动态页面片段缓存 30 秒，减少短时间返回已打开页面的 RSC 往返。这不是共享 HTTP 缓存，私有 API 仍正常鉴权。

## 验证与后续边界

回归覆盖后台 session 刷新时文档不重读、本地副本先显示且等待版本校验、加载超时/取消/重试、原图按需加载，以及登录态恢复。

这些代码修改不改变香港与美国的带宽、丢包或服务器负载，也不会把私有图片变成香港公开静态文件。私有图片继续通过美国鉴权接口。不能把所有 `/api/assets/*` 改成匿名共享缓存来追求速度。

上线后先看 Img 请求的耗时、大小、`Server-Timing`（authorize/preview）与浏览器 Timing 中的等待/下载时间，再决定是预览持久化、带鉴权的香港图片缓存，还是更换线路。若香港本地极小资源依旧数秒，应分别从香港本机和国内网络测同一静态 URL，区分源站计算与入口线路。
