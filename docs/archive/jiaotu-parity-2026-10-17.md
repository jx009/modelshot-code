### 流畅度：具体优化与可验证边界

1. **预览分级**：根据画布投影尺寸与DPR选择320/640/1280预览。原图先有预览再加载；只有原始长边超过1280、图片覆盖至少40%视口时请求原图。可选原图失败仍保留预览。
2. **并发限制**：图片下载/解码最多4路；相同URL共享Promise，缓存最多32项。失败会释放队列槽位，单次超时25秒、最多两次尝试。图片设置异步解码并等待 `decode()`。
3. **取消语义**：离开视口卸载图片引用，过期组件订阅不再写入React状态。由于多个调用者共享任务，取消一个订阅不强制中断底层共享下载；不宣称整个网络任务都被取消。
4. **隔离重绘**：图片节点memo化，画布/选区分层；聊天输入不重画64个未变更图层；相机通知合并到帧内。
5. **任务状态**：浏览器先恢复已有任务，活跃期间订阅SSE；断线回退状态查询。服务端每2秒读任务快照、约10秒心跳、45秒轮换连接；完整快照+哈希ID使漏帧不会丢最终状态。它是任务状态流，不是图片像素流或LLM token流。
6. **无打断交付**：用户还在输入或聚焦表单时，后台结果不会抢走视角或移动端聊天标签；结果预览失败可重新加载，不重新调用模型或扣费。
7. **局部调色**：预览限制像素规模；应用/导出再使用原尺寸算法。长图超大图最终处理仍有浏览器CPU/内存开销。

有界队列的核心代码位于 `src/lib/studio/image-queue.js`：

```js
while (active < limit && pending.length) {
  const { run, resolve, reject } = pending.shift();
  active++;
  Promise.resolve().then(run).then(resolve, reject).finally(() => {
    active--;
    drain();
  });
}
```

### 画布选择与编辑语义

- `selectionGroup` 表示用户组合；`groupId` 继续表示模型拆层来源。拆层中的物体不会因为来源相同而被错误地整体移动。
- 空白拖框选中相交图层，Shift可累加；锁定与隐藏层不参与拖框。
- 多选时共用一个Transformer，四角等比缩放和整体旋转；整组一次提交，撤销一次回到操作前。锁定图层不参与变换。
- 多选/组合拖动保留相对位置；六向对齐使用旋转后的包围盒，三个以上图层可横向等距排列。
- 右键提供复制、组合/解组、置顶/置底、锁定/解锁、删除；空白右键提供全选和适应画布。复制时重新分配用户组合ID，避免副本与原图意外联动。
- `MultiSelectionTransform.jsx` 将临时Konva scale归一化为图层尺寸；提交给 `commitLayers`，继而进入50步撤销与现有版本化保存。

### 电商 Agent 的实际能力

保留当前 `commerce/agent` 的视觉规划和多轮定向修订，重新设计入口和场景控制。新增选择生成的场景、逐场景提示词/标题/比例编辑、成本重算、整份配方复制。修改已生成场景的提示词或比例会增加attempt并保留旧结果，下一次生成有独立幂等键；复制配方创建新项目，不复用旧任务ID。

当前通用多步骤计划仍由浏览器按步骤编排，单步由持久化Worker完成；关闭页面后运行中的单步可完成，未提交的后续步骤需要恢复页面继续。它尚不是脱离浏览器持续运行、可自动评估重试整个计划的服务端Agent。电商文案语言仍为中/英、市场为CN/US/EU，与图片翻译的10种语言是两套能力。
