# 延期验收清单

以下项目由用户明确允许暂缓。状态全部为未验收；开发候选版本不得据此宣称商业质量、平台过审或生产可靠性。负责人是职责分工，具体人员需在发布前指定。

| 项目 | 责任角色 | 执行步骤 | 通过标准 |
| --- | --- | --- | --- |
| 真实 AI 供应商 | 模型集成负责人 | 为每个启用 provider/model 收集真实服装、图案、颜色、版型样本，检查控制、取消/查询、异常和成本 | 输入支持与能力表一致；出图质量和误差范围有样本报告；成本无未解释差异 |
| Stripe | 支付负责人 | 测试模式完成购买、延迟付款、续费、取消、变更、部分退款、争议、事件重放 | 每笔实际付款、权益、退款、佣金守恒；票据及 webhook 配置有效 |
| Google / 邮件 | 身份负责人 | 注册、登录、重置密码、过期码、送达与退信，验证重定向域名 | 无账号串用；旧会话撤销；邮件可送达；恢复流程有人负责 |
| 云对象存储 | 平台负责人 | 私有 bucket 权限、跨实例读取、删除保留期、对象备份还原 | 无公共用户原图；恢复后 checksum 与引用匹配 |
| C2PA | 内容来源负责人 | 使用自有真实证书签名并由独立验证器检查最终下载文件 | 转换后签名有效，信任链与展示准确；未签名清晰标记 |
| 部署和监控 | 运维负责人 | Worker 重启、Redis 故障、网络超时、多实例压测、告警通知和数据库对象恢复 | 有可追踪告警、满足约定 RPO/RTO、无超额扣费与无法定位的任务 |
| 法律及素材授权 | 产品负责人 | 核验模特授权、样例来源、供应商条款、目标电商平台要求 | 授权可追溯；没有未经证明的商业权利或过审承诺 |
| 用户体验 | 产品与 QA | 真实桌面/移动浏览器完成实际 SKU 工作流，中英文和明暗主题 | 核心操作无阻断，真实长文本与真实图片可检查 |

启用开关：`PAYMENTS_ENABLED=1`、`QA_ENABLED=1`、`C2PA_ENABLED=1` 分别在相应验收完成后启用；供应商在后台配置并激活。不使用演示供应商或测试证书冒充真实完成。

记录每项执行日期、人员、测试账户/对象 ID、报告位置和结论到本文件后再发布。
