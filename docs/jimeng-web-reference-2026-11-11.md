### 采用的交互规格

1. 左侧保留轻量工具入口，主体为可平移缩放的画布；图片与视频都是独立作品。
2. 选中图片的工具条直接提供生成视频。面板使用统一素材、参数和报价，灰态给出实际能力原因。
3. 来源关系仅从实际提交的资产和任务生成。删除来源节点后允许保留结果，不能自动引用替代资产。
4. 任务占位显示已确认状态，完成后由结果接替；不将占位解释为供应商提供的排队名次或百分比。
5. 本项目方案指定视频侧栏，录屏展示节点下方浮层。容器差异明确保留，不能宣称两者位置逐像素相同；控件顺序对齐参考素材 → 提示词 → 参数／费用 → 提交。
