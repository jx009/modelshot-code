# 腾讯 COS 长期图片存储与私有加速：配置与运行

适用：来塔绘梦（letaidraw），2026-10-19。

## 1. 现在图片在哪里

仓库的 `compose.prod.yaml` 将应用连接到 `http://storage:9000`。`storage` 是 MinIO 容器，数据存于美国部署机器上的 Docker `storage-data` 数据卷；不是腾讯 COS。本结论来自部署配置，未登录生产服务器核对实际数据卷。

原图继续由 MinIO 保存，数据库 `Asset.objectKey`、下载、模型输入和导出流程保持原来的存储地址。不要删除 MinIO、数据卷或原有 S3 环境变量。

## 2. 这次加速什么

请求路径：

1. 浏览器请求香港入口的 `/api/assets/{id}?preview=1280&delivery=auto`。
2. 美国应用检查登录、图片所有者和图片状态。
3. 副本就绪时，返回不允许缓存的 307 跳转；浏览器直接从所配置地域的腾讯 COS 下载图片。
4. 副本未就绪时，直接返回原库存储的图片，并持久化提交后台同步任务。同步完成后再次加载可走 COS。
5. 如果 COS 图片加载失败、签名失效、跨域设置不正确或副本被人工删除，画布加载器会重试 `delivery=proxy`，回到原库存储，同时请求修复副本。

这能减少图片字节反复从美国跨洋传输。登录鉴权和页面/API 仍在美国，首次冷图仍可能从美国下载；不能承诺切页和所有请求都瞬间完成。COS 是托管对象存储，不需要在香港服务器安装一个 COS 服务。

当前画布的共享图片加载器自动启用 COS 直连，涵盖它加载的预览与原图。普通图片 API、下载链接、视频和 ZIP 导出仍使用现有同源路径，避免破坏下载/权限行为。灵感页公开示例素材不在这次私有素材加速范围内。

## 3. 部署更新

GitHub Action 生成镜像后，在美国项目部署目录执行：

```sh
sh scripts/deploy-update.sh
```

脚本会先执行数据库迁移，再更新 web 和 worker。本次新增 `AssetDelivery` 就绪记录表。web 与 worker 都要更新；只更新前端不会启动同步工作。

香港已有全站反向代理可以继续使用。不要在香港给 `/api/assets/` 配置共享缓存，不要缓存含签名的 307 响应。图片副本通过浏览器直接访问 COS，无需向香港上传 COS 密钥，也无需修改现有域名解析。

## 4. 准备存储桶

在腾讯云 COS 控制台创建或选择存储桶：

- 新建时建议使用香港地域 `ap-hongkong`，存储类型标准存储。
- 权限设置为 **私有读写**，不要开启公共读或匿名桶策略。
- 复制包含 APPID 的完整桶名，例如 `letaidraw-1250000000`。
- 已有桶可以复用，但地域必须填该桶的实际地域；填 `ap-hongkong` 不会把其他地域的桶移动到香港。
- 建议使用专用前缀 `letaidraw`，避免与其他项目混在一起。
- 关闭该项目目录的到期删除和转归档生命周期规则；应用不会主动给有效图片设置过期时间，但腾讯桶已有的生命周期规则仍会生效。请使用标准存储，归档文件不能即时读取。

这一版使用 COS 官方 HTTPS 域名 `https://{bucket}.cos.{region}.myqcloud.com`。不需要购买额外服务器，也不要求配置自定义域名或 CDN。若以后使用 CDN，需要额外设计 CDN 鉴权和回源规则，不能把私有桶直接改成公开桶。

## 5. 获取访问密钥与权限

在腾讯云访问管理 CAM 中创建专用子用户并为它创建 API 访问密钥，取得 `SecretId` 和 `SecretKey`。不要把密钥发到聊天或放到前端代码中。

用自定义策略授权指定桶与前缀即可，所需操作：

| 资源范围 | 操作 | 用途 |
| --- | --- | --- |
| 指定存储桶 | `cos:GetBucketACL` | 测试与后台同步前确认桶的 ACL 不是公开读写 |
| 指定桶下 `letaidraw/*` | `cos:PutObject` | 上传图片、预览和测试文件 |
| 同上 | `cos:PutObjectACL` | 上传时显式设置对象为 private |
| 同上 | `cos:GetObject` | 测试读取与签名后的浏览器访问 |
| 同上 | `cos:DeleteObject` | 删除测试对象及已清理的图片副本 |

请在 CAM 策略生成器选择实际桶、地域、APPID 和上述目录资源；如果修改了前缀，要同步修改授权。无需授予整个账号所有 COS 存储桶的管理权限。

存储桶 ACL 测试不能替代检查已有的桶策略：请同时移除会给匿名用户读取权限的桶策略。

## 6. 配置跨域 CORS

进入存储桶的「安全管理 → 跨域访问 CORS」，添加：

| 字段 | 填写 |
| --- | --- |
| 来源 Origin | `*` |
| 方法 | `GET`、`HEAD`、`PUT` |
| 允许 Headers | `*` |
| 暴露 Headers | `ETag`、`Content-Length`、`Content-Range` |
| 缓存时间 | `600` 秒 |

画布需将跨域图片绘制到 Canvas 并导出。这里使用匿名 CORS + URL 签名，COS 请求不携带本站登录 Cookie。`*` 仅允许浏览器跨域读取已授权的响应，不赋予私有对象匿名下载权限。也覆盖了跨域重定向可能产生的 `Origin: null`；如改为域名白名单，需要对实际重定向流程重新做跨域测试。

防盗链规则若禁止空 Referer，可能导致签名 URL 也无法在画布中读取；请结合管理页的浏览器测试检查。不要把签名参数记录到公开日志或分享为永久链接。

## 7. 在来塔管理台填写

打开 **管理台 → 云存储与图片加速**，路径 `/zh/admin/storage`。

1. 填完整桶名、真实地域和专用前缀。
2. 填 SecretId 和 SecretKey。后续编辑时留空会保留已保存的凭据，不会清除它们。
3. 签名有效期建议保留 `300` 秒，可设置 `60–900` 秒。
4. 先点「测试连接与跨域」。测试当前表单，不会自动保存。
5. 测试会检查桶 ACL，真实上传/读取/删除一个随机小文件，再让当前浏览器使用与正式上传相同的签名和请求头 PUT 测试 PNG，最后加载 PNG 并执行 Canvas 像素读取。仅服务器读写和浏览器 GET 通过，不代表浏览器 PUT 可用。
6. 全部通过后勾选「启用 COS 长期存储与加速」，点击「保存配置」。后台进程最多约 60 秒读取新配置。

SecretId 与 SecretKey 随整份 COS 配置使用现有 `ENCRYPTION_KEY` 加密保存。管理 API 不返回密钥，操作审计不保存密钥。请保持美国 web 和 worker 的 `ENCRYPTION_KEY` 一致，部署后不要随意更换。

测试会保留一张极小的 `letaidraw/diagnostics/browser-probe.png` 供浏览器验证，浏览器 PUT 覆盖同一测试对象，不产生额外文件；随机文本测试对象会删除。测试返回的 PNG 读取地址仅有效 60 秒，PUT 地址与正式直传一样有效 900 秒。

已有桶从图片读取加速升级为浏览器直传时，必须在原 CORS 规则中补上 `PUT`，并允许 `Content-Type` 请求头。否则图片可以正常显示，上传仍会被浏览器阻止。修改后重新运行「测试连接与跨域」并重试上传。

素材库、首页和画布上传共用同一条 `/api/upload/direct` → 浏览器 COS PUT → 上传确认流程。2026-10-21 排查的线上配置中，本站来源的 GET / HEAD 预检返回 200，允许方法仅为 `GET,HEAD`；PUT 预检返回 403 `AccessForbidden`，消息为 `CORSResponse: This CORS request is not allowed`。这种情况必须在腾讯云补齐 PUT 规则；代码更新提供准确报错与真实 PUT 测试，不会自动修改存储桶 CORS，也不会在直传失败后悄悄改为美国服务器中转。

## 8. 如何确认生效

1. 新上传或生成一张图片，等待后台同步。
2. 打开画布，浏览器 Network 筛选 `assets`。
3. `delivery=auto` 请求命中副本时返回 307，响应头 `X-Asset-Delivery: cos`。
4. 随后的实际图片请求域名应为你的桶域名，URL 包含短期签名。
5. 管理台刷新后「已同步 N 张原图」增加。
6. 在控制台可看到 `letaidraw/assets/v1/` 下的原图及三种 WebP 预览。

旧图按需同步，不会在刚开启时立即全库迁移。第一次打开旧画布可能仍走美国，第二次在后台同步完成后再观察。浏览器已有本地图片缓存时可能不出现新的网络请求，这是正常缓存命中。

## 9. 运行细节与回退

- MinIO 持久化预览在 `_previews/v1/` 下，尺寸 320/640/1280；重启应用不必重新解码所有原图。
- 图片同步通过已有数据库 Outbox 持久化，再送入独立的 BullMQ 队列 `modelshot-asset-mirror-v1`，并发 2，失败指数退避重试 5 次。它不占用生成队列的并发名额。
- 就绪记录在本地数据库查询，正常命中不必先跨洋向 COS 发 HEAD 请求。
- 已上传的原图、320/640/1280 预览与就绪记录长期保留，不再设置 24 小时的副本失效时间，不因图片变旧而重复上传或回美国下载。短期签名到期只撤销该链接访问权限；再次访问会签发新链接，不会删除对象。上传失败不会写就绪记录，未同步图片继续从原库读取。
- 同一图片的重复排队以 10 分钟窗口去重；失败后再次访问可在后续窗口重新提交。
- 关闭加速后，从原库读取仍可用。已有签名 URL 到期前仍有效，不能瞬间撤销已下载的副本。
- 软删除立即阻止新的图片授权。现有清理任务在原有保留期限到期后删除原图和持久化预览，并持久化排队删除当前配置的 COS 副本；COS 删除也在独立队列重试，不阻塞生图调度。重试耗尽的任务保留 7 天供运维排查，届时可重试队列任务或在桶中清理对应对象。
- 修改密钥会更新就绪记录标识并重新同步；原始图片不受影响。
- 更换存储桶、地域或前缀后，不会自动访问旧桶删除副本。确认旧配置停用后，请在 COS 控制台仅清理旧的项目专用目录。不要给正在使用的目录设置短期自动删除规则。
- COS 存储/请求/外网下载会产生费用，本次没有开启收费的全局加速功能或 CDN。

## 10. 常见失败

| 管理页提示/现象 | 检查 |
| --- | --- |
| 找不到存储桶 | 桶名是否含 APPID，地域是否真实一致 |
| 权限不足 | 子用户策略是否覆盖桶 ACL 和该前缀的对象操作 |
| 签名不匹配 | SecretId 与 SecretKey 是否来自同一组密钥 |
| 时间偏差 | 同步美国服务器系统时间 |
| 服务器读写通过，浏览器失败 | CORS、Referer 防盗链、浏览器到 COS 的网络 |
| 长时间没有副本 | worker 是否更新，是否有 `COS_MIRROR_RETRY` 或 `COS_WORKER_ERROR` 日志 |
| 画布有图但不走 COS | 是否已启用、同步是否完成、是否直接命中浏览器本地缓存 |
| 新旧配置切换后仍走旧配置 | 等待最多约 60 秒，检查 web/worker 的数据库与加密密钥是否一致 |
